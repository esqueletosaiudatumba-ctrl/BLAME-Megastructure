## The packaging blocker (read this first)

The handoff zip was **missing `mod/build.gradle`**, so `./gradlew build` silently did nothing
(`buildEnvironment` only). I reconstructed it. The dependencies:
- Gradle wrapper 9.7.0 (already in the repo) — works on JDK 25.
- plugin id is `com.gtnewhorizons.retrofuturagradle` (the marker artifact lives at
  `nexus.gtnewhorizons.com/.../com/gtnewhorizons/retrofuturagradle/`; the id
  `com.cleanroommc.gradle.retrofuturagradle` that older docs mention does **not** resolve).
  Versions available: 1.4.5 … 2.0.6.
- `mod/settings.gradle` needed the plugin-marker group added to the GTNH repo filter
  (only `com.gtnewhorizons` and `com.gtnewhorizons.retrofuturagradle` are needed).
- `gradle/scripts/dependencies.gradle` calls `tasks.shadowJar{}`, so
  `com.gradleup.shadow` (9.6.1) had to be added even though nothing is shaded.
- `archivesBaseName` no longer exists in Gradle 9 → `base.archivesName`.
- `minecraft { mappings ... }` is not a valid DSL in RFG 2.0.6; mappings come from
  `gradle.properties` (`mapping_channel=stable`, `mapping_version=39`), which was already set.
- `processResources` must expand `${...}` placeholders in `mcmod.info`/`pack.mcmeta`
  (done with an Ant `ReplaceTokens` filter, `${begin}…${end}`, with literal fallbacks so empty
  properties never break the build).

The rebuilt jar must land at `mod/build/libs/blamegen-1.0.0.jar`. `tools/package-instance.ps1`
then stages `instance-pkg/` → `BLAME_Megastructure_Instance.zip`.

## How to build and package

```
cd "C:\Users\Admin\Documents\Projeto Padrão\mod"
$env:JAVA_HOME="C:\Users\Admin\AppData\Roaming\ElyPrismLauncher\java\java-runtime-epsilon"
.\gradlew.bat build --no-daemon --console=plain
cd ..
powershell -File tools\package-instance.ps1
```

If the mod jar cannot be built, **do not ship a stale v1 jar with v3 core classes**:
`Mat.COUNT` and friends are `static final` compile-time constants inlined into
`BlameCubeGenerator.class`, so a v1 generator + v3 `Mat` causes an
`ArrayIndexOutOfBoundsException` in `buildStates()` at world-creation time. Rebuild the jar,
or ship the instance without it and say so.
